# 实现状态（开发分支）

更新时间：2026-11-15

## 已实现并通过自动化测试
- DeepSeek Harness bundle 基础包结构与 Cordis 插件入口。
- Harness 原生销售指导提示：客户分析、意向与购买力分离、三种客户原语言回复草稿、禁止自动发送与禁止擅自报价。
- 本地客户内容建档、客户检索、跟进记录工具。
- 客户承诺、我方承诺、双方约定分开保存。
- 意向等级与购买力独立校验。
- 原始提交内容按事件追加，不覆盖旧记录。
- AES-256-GCM 加密客户数据库；密钥通过 DeepSeek Harness 本地凭据服务保存。
- 本地加密备份、备份列表、恢复前安全快照和恢复校验。
- 密文文件原子替换、尽可能限制目录/文件权限；损坏或密钥不匹配时拒绝覆盖。

## 尚未验收
- 在目标 DeepSeek Harness 桌面应用中真实安装、启用和多轮会话验收。
- 人类可读的完整导出与数据迁移 UI。
- 图片、PDF、OCR 导入。
- 完整客户去重/身份合并工作流和客户长期记忆检索优化。
- 国家/港口知识、Incoterms 2020 规则、报价/利润计算。
- 多 Harness 适配和其他中国模型平台实测。

本地自动化测试不等于 Harness 桌面端实机验收。凭据文件与客户库都在同一 OS 用户权限边界内；不防御已控制该用户账户的恶意程序。
