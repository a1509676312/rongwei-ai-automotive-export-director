# 实现状态（开发分支）

更新时间：2026-11-15

## 已实现（自动化测试/CI 验收以最新 Actions 结果为准）
- DeepSeek Harness bundle 基础包结构与 Cordis 插件入口。
- Harness 原生销售指导提示：客户分析、意向与购买力分离、三种客户原语言回复草稿、禁止自动发送与禁止擅自报价。
- 本地客户内容建档、客户检索、跟进记录工具。
- 客户电话/WhatsApp/邮箱完全匹配时追加唯一档案；联系方式匹配多个档案时拒绝猜测；姓名与公司同时匹配但无联系方式时要求人工确认。
- 客户搜索返回最近历史事件、客户回应、评级依据及未完成承诺（每客户可配置返回最近 1–20 条）。
- 客户承诺、我方承诺、双方约定分开保存。
- 填写意向等级或购买力时，程序强制要求原话/事实证据。
- 原始提交内容按事件追加，不覆盖旧记录。
- AES-256-GCM 加密客户数据库；密钥通过 DeepSeek Harness 本地凭据服务保存。
- 本地加密备份、备份列表、恢复前安全快照和恢复校验。
- 本地销售经验记录/检索，明确区分单次经验、重复规律、已验证经验；重复/已验证经验必须有去标识化证据。
- 本地目的国/港口/内陆目的地资料记录与检索，强制标注已核实、历史参考、AI 推测或过期状态；标记已核实必须提供来源。
- FOB/CIF/CIP（Incoterms 2020）内部成本、毛利和利润率计算；不估算缺失成本，不自动生成客户报价。
- 密文文件原子替换、尽可能限制目录/文件权限；损坏或密钥不匹配时拒绝覆盖。

## 尚未实现或尚未验收
- 目标 DeepSeek Harness 桌面应用中真实安装、启用、模型工具调用和多轮会话验收。
- 人类可读的完整导出、跨设备迁移与恢复 UI。
- 图片、PDF、OCR 导入及车型图像识别。
- 完整客户身份合并/拆分和更丰富的长期记忆摘要检索。
- 已核实的国家/港口/内陆运输资料内容库（当前仅有本地资料记录与检索能力，不内置未经核实的国家事实）。
- 报价计算的完整业务费用项、保险金额/条款校验、汇率与有效期管理、公司利润规则配置。
- 供应商成本/公司资料管理。
- 广告来源归因。
- 多 Harness 适配和其他中国模型平台逐一实测。

## 验收边界
- GitHub Actions 单元测试、打包检查和 CLI 插件加载检查不能证明 DeepSeek Harness 桌面端真实模型会话可用。
- 当前数据加密保护本机客户库，但不防御已控制该 OS 用户账户的恶意程序。
- 销售经验和目的地知识均为每个安装用户的本地数据，不跨用户共享；目的地资料状态和来源必须随检索结果展示。
