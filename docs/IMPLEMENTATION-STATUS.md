# 实现状态（开发分支）

更新时间：2026-11-15

## 已实现并由 CI 自动化测试覆盖
- DeepSeek Harness bundle 基础包结构、Cordis 插件入口及工具注册。
- 销售指导：客户分析、意向/购买力分离、三种客户原语言回复草稿、禁止自动发送、禁止擅自报价。
- 本地客户建档、联系方式去重辅助、历史事件、跟进记录和承诺闭环。
- 客户/我方/双方承诺分开保存，支持完成/取消状态更新并保留历史。
- 意向和购买力评级必须附客户原话或事实证据。
- 附件已读取文本的本地留档，保存原文件名、MIME、提取方式和置信度；工具不读取二进制文件、不执行 OCR。
- AES-256-GCM 本地加密客户库、加密备份、恢复前快照和安全恢复。
- 用户明确确认后生成明文 JSON 全量导出并支持导入；支持 merge/replace，导入前自动创建加密安全快照；导出目录和文件尽可能限制为 0700/0600 权限。
- 本地销售经验沉淀/检索，区分单次、重复、已验证；检测疑似邮箱/电话号码并要求去标识化。
- 本地目的国/港口/内陆目的地资料记录/检索，保留状态、来源、核实时间和过期状态。
- 本地公司资料、供应商/车型成本、成本来源和有效期管理。
- 广告平台/来源/活动/素材归因，按唯一客户计数，不把线索数冒充成交数。
- FOB/CIF/CIP 内部成本、毛利和毛利率计算；使用货币最小单位整数运算，支持常见 0/2/3 位小数币种；跨币种换算必须提供来源、日期、有效期和汇率，过期汇率拒绝计算；检查海运术语运输方式、保险金额比例和保险条款提示；不生成客户报价。

## 尚未完成或尚未实机验收
- DeepSeek Harness 桌面应用的真实安装、启用、模型工具调用和多轮会话。
- 插件自身读取二进制图片/PDF、扫描件 OCR 和车型图像识别。当前只保存 Harness 模型已实际读取的附件文字；不包含 OCR 引擎。
- 具备权威来源、定期更新的国家/港口/内陆运输资料库（目前提供本地资料模型和用户资料沉淀，不内置未经核实的目的地事实）。
- 完整跨设备迁移 UI。已有明确确认的 JSON 导出/导入、merge/replace 和导入前安全快照，但需要用户手动将导出文件复制到另一设备的 exports 目录。
- 多 Harness 适配和其他中国模型平台逐一实测。

## 验收边界
- 最新 CI 测试会运行语法检查、单元测试、npm pack dry-run 和 DeepSeek Harness CLI 安装/配置加载 smoke test。
- CLI 安装成功不代表桌面端真实模型会话成功；该项留给 Codex 在用户电脑上一次性验收。
- 当前数据加密不能防御已控制同一 OS 用户账户的恶意程序；云端模型处理遵循其供应商数据政策。
- 销售经验、目的地资料、供应商、公司资料和广告归因均为本机数据，不跨用户共享。
