# 产品开发基准（2026-11-15）

本文件将用户提供的《Rongwei AI 汽车出口销售总监插件——完整需求说明书》固化为开发约束。

## 产品形态
- AI Harness 原生插件；首要目标 DeepSeek Harness。
- 不做独立网页聊天系统、桌面聊天机器人、WhatsApp/Telegram/社媒消息接入。
- 默认简体中文；多模型平台分别适配和实测，不以 API 可用性代替平台兼容性证明。

## 销售能力
- 从用户主动提交的聊天/截图/业务资料中抽取客户事实；未知字段保持未知并保留来源、时间。
- 独立评估购买意向与购买力；S/A/B/C/D 是销售判断，不是成交概率。
- 每次回复至少三种策略、客户原语言草稿及中文解释；不得报价臆测、编造事实或自动发送。
- 识别客户类型、阶段、异议、承诺事项和下一步动作。

## 业务能力
- 国家、城市、港口/内陆目的地知识库；确认信息、历史参考、AI 推测、过期信息分级。
- FOB/CIF/CIP 按 Incoterms 2020 规则处理；风险转移与费用承担必须区分。
- 报价计算使用程序逻辑，检查成本、运输、保险、汇率、目的地、术语、利润门槛及有效期。
- 供应商成本与公司资料是可选业务资料，不是固定库存/固定售价系统。
- 客户跟进须分别记录客户承诺、我方承诺和双方约定。

## 记忆与学习
- 客户记忆按客户隔离；保留原始记录、来源、时间、人工修订历史。
- 从用户选择/修改回复及客户结果积累本地经验；区分已验证、多次规律、单次经验和 AI 推测。
- 禁止跨用户共享客户数据或默认上传公共知识库。

## 数据与安全
- 本地优先、每个使用者独立本地数据库；加密备份、增量备份、历史恢复和完整导出。
- 数据损坏时不覆盖原始数据。
- 默认不启用客户数据遥测、云端记忆或第三方原文上传。
- 客户自动建档仅在用户主动提交信息后自动进行，不代表绕过模型供应商或第三方服务的数据传输告知。

## 低算力
- 仅分析新增内容；摘要代替全量历史；规则/数据库处理检索、报价、利润、日期和提醒。
- 普通模型合并完成常规分析；高级模型按需调用；不使用持续多智能体讨论或后台 AI。

## 明确不开发
独立聊天网页、消息渠道接入/自动发送、员工 CRM、库存系统、固定价格系统、独立付款风险模块、持续多智能体讨论。
