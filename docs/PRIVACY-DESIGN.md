# 隐私与数据隔离设计要求

本文件是实现约束；各功能实现状态以 `docs/IMPLEMENTATION-STATUS.md` 为准。

- 每个安装用户使用独立本地数据目录；不同用户之间无同步、无共享。
- GitHub 仅托管公开源码与不含真实客户资料的通用文档。
- 当前客户数据库使用 AES-256-GCM 加密；密钥由 DeepSeek Harness 本地凭据服务保存。
- 当前密钥仍处于同一 OS 用户权限边界内；不防御已控制该用户账户的恶意程序。
- 默认关闭客户数据遥测、云端记忆同步和公共经验上传。
- 本地客户记录须保留来源、时间、可信状态与人工修订历史。
- 客户自动建档仅指在用户主动提交内容后自动创建/更新本地档案；不意味着绕过操作系统、模型供应商或第三方服务的权限与隐私要求。
- 调用云端模型前明确告知必要的数据传输范围；尽量脱敏、摘要化和最小化。
- ModSearch、ModLens、MinerU、MemSearch 等外部组件必须逐一评估数据流；未经核验不得默认启用客户资料上传。
- 客户资料不得用于跨用户训练或共享经验库。可共享的仅限用户明确选择发布的、去标识化且无法回溯个人/客户的通用规则。
