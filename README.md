# Rongwei AI 汽车出口销售总监

面向全球汽车出口业务的 AI 原生 Harness 插件。项目以本地优先、低算力、证据可追溯和客户数据隔离为基本原则。

## 项目状态

当前为全新项目初始化阶段。尚未宣称兼容任何 Harness 或模型平台；每个平台必须独立适配并完成实机验收。

## 核心边界

- 不开发独立网页聊天系统、聊天软件或消息渠道机器人。
- 不自动向客户发送消息；只生成由用户手动发送的回复草稿。
- 不建立公共客户数据库，不将客户资料提交到本仓库。
- 客户原始聊天、图片、报价和记忆默认保存在使用者本地。
- 未知信息明确标记为未知；不虚构车型、法规、价格、运费、保险或客户购买力。
- 本地规则负责检索、计算、提醒和存储；模型按需调用。
- Codex 仅用于测试、构建验证和安装验收，不承担插件实现。

## 安全提示

本仓库是公开源码仓库。严禁提交客户姓名、联系方式、聊天截图、报价、供应商成本、密钥、访问令牌、数据库、备份或任何真实商业数据。云端模型或第三方解析服务可能接收被提交处理的内容；本地保存不等于模型调用时零传输。

## 开发阶段

1. 原生插件协议与工具注册、客户本地存储、客户识别与记忆。
2. 国家/港口知识库、FOB/CIF/CIP 计算与报价校验。
3. 跟进闭环、销售经验学习、广告归因。
4. 各模型与 Harness 独立适配和真实测试。
5. 安装包、升级、备份恢复、安全检查与销售专项验收。

## 贡献与代码控制

正式版本以 `main` 为准。公开仓库允许查看和 fork，不代表任何人获得本仓库写入权限。未经仓库所有者批准的代码不得合并到 `main`。安全问题请私下联系仓库所有者，不要公开提交客户数据或漏洞利用细节。
