# Rongwei AI 汽车出口销售总监插件

本仓库是独立开发的 DeepSeek Harness 原生插件项目。产品约束见 [产品需求基准](docs/PRODUCT-BASELINE.md)，隐私边界见 [隐私设计](docs/PRIVACY-DESIGN.md)。

## 当前开发分支能力

- 客户建档、联系方式去重辅助、客户历史事件和跟进记录。
- 意向等级与购买力独立评估，评级必须提供原话/事实证据。
- 客户、我方、双方承诺分别记录，并可更新为已完成或已取消。
- 每次客户回复要求至少三种不同策略、客户原语言草稿及中文解释；只生成草稿，不自动发送、不擅自报价。
- 本地 AES-256-GCM 加密客户数据、加密备份、备份恢复和恢复前安全快照。
- 用户明确确认后生成明文 JSON 全量导出；导出文件包含敏感数据，默认文件权限 0600。
- 本地销售经验、目的国/港口资料、供应商成本、公司资料和广告客户来源归因。
- FOB/CIF/CIP（Incoterms 2020）内部成本和毛利计算，使用货币最小单位整数运算，支持常见 0/2/3 位小数币种；不生成客户报价。
- 附件文字留档：当 Harness 当前模型实际能够读取图片或文档时，可记录提取文本、文件名、提取方式和置信度。

## 附件与 OCR 边界

本插件不会自行打开任意附件路径，也不内置 OCR 模型。PNG/JPEG 等图片是否能被理解，取决于用户当前 DeepSeek Harness 模型和其原生多模态附件能力；PDF 文字层是否可见，取决于 Harness 的文档处理管线。rongwei_attachment_capture 只保存模型/用户已经实际读取的文本，不会谎称完成二进制解析或 OCR。扫描件 OCR 需要另行评估可信的本地方案、依赖体积、CPU/内存、语言包、许可和 Harness 集成方式；当前不偷偷下载模型或把客户附件发送给第三方。

## 运行要求

- 目标 Harness：DeepSeek Harness CLI/桌面版；插件 API 基线按 DSH 0.2.2 系列验证。
- Node.js：24.9.0 或更高版本。
- 客户库默认位于本机 ~/.rongwei-ai/customers.json，采用 AES-256-GCM 加密；密钥由 Harness 本地凭据服务保存。
- 明文导出位于 ~/.rongwei-ai/exports；请妥善保管，不要上传公共仓库或发送给无关人员。

## 隐私和安全

- 公共仓库只保存源码、通用文档和合成测试数据；真实客户数据、附件、报价、密钥不得提交到 GitHub。
- 所有客户、供应商、公司资料、销售经验、目的地资料和归因数据均为本机数据，不跨用户共享。
- 明文导出仅在用户明确确认后生成。
- 本地加密不能阻止当前操作系统用户账户已被恶意程序控制，也不能阻止用户主动提交给云端模型的内容按模型供应商政策处理。

## 开发规则

- 所有功能开发在 develop；未经项目所有者批准，不写入或合并到 main。
- Codex 只负责测试、构建、安装验证，不代替项目开发。
- GitHub Actions 通过不等于 DeepSeek Harness 桌面端真实模型会话验收。
- 不声称未实测的平台、模型、OCR 或图像识别能力已经兼容。
