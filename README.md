# Rongwei AI 汽车出口销售总监插件

本仓库是全新开发的 DeepSeek Harness 原生插件项目。开发基准见 [产品需求基准](docs/PRODUCT-BASELINE.md)，隐私边界见 [隐私设计](docs/PRIVACY-DESIGN.md)。

## 当前开发状态

当前开发分支已加入第一版本地客户记忆核心：客户内容建档、客户搜索、跟进记录，以及客户/我方/双方承诺事项分开记录。它仍处于开发阶段，尚未通过 DeepSeek Harness 实机安装验收。

插件包入口位于仓库根目录，目标 Harness 协议基线为 DSH 0.2.2-rc.2，运行时要求 Node.js 24.9.0 或更高版本。

## 隐私

- 公开仓库只存放源码和通用文档。
- 真实客户聊天、客户资料、报价、附件、备份和密钥不得提交到仓库。
- 当前客户记录写入本机 `~/.rongwei-ai`，不由插件上传网络。
- 本地存储不能阻止用户主动提交给云端模型的内容被模型供应商处理；请在使用云端模型前了解其数据政策。

## 开发规则

- `main` 是正式稳定分支；功能开发在 `develop` 或独立功能分支进行。
- 未经项目所有者批准，不向 `main` 合并或直接写入。
- Codex 的职责是测试、构建和安装验证，不代替本项目的产品开发。
- 未通过目标 Harness 实机测试的功能，不标记为已验收。
