# Rongwei AI 汽车出口销售总监插件

本仓库是全新开发的 DeepSeek Harness 原生插件项目。开发基准见 [产品需求基准](docs/PRODUCT-BASELINE.md)，隐私边界见 [隐私设计](docs/PRIVACY-DESIGN.md)。

## 当前开发状态

当前开发分支包含第一版销售指导提示和本地客户记忆核心：客户内容建档、客户搜索、跟进记录、客户/我方/双方承诺事项分开记录，以及加密备份、备份列表和安全恢复。客户数据库使用 AES-256-GCM 加密，密钥由 DeepSeek Harness 本地凭据服务保存。它仍处于开发阶段，尚未通过 DeepSeek Harness 桌面端实机安装验收。

插件包入口位于仓库根目录，目标 Harness 协议基线为 DSH 0.2.2-rc.2 或更新的兼容版本，运行时要求 Node.js 24.9.0 或更高版本。

## 隐私

- 公开仓库只存放源码和通用文档。
- 真实客户聊天、客户资料、报价、附件、备份和密钥不得提交到仓库。
- 客户库默认写入本机 `~/.rongwei-ai/customers.json`，采用 AES-256-GCM 加密；密钥保存在 Harness 本地凭据服务中。
- 加密备份保存在本机 `~/.rongwei-ai/backups`；恢复前会自动保存当前数据库快照。
- 当前密钥存储依赖同一操作系统用户的本地凭据文件权限；它不防御已控制当前 OS 用户账户的恶意程序。
- 本地存储不能阻止用户主动提交给云端模型的内容被模型供应商处理；请在使用云端模型前了解其数据政策。

## 开发规则

- `main` 是正式稳定分支；功能开发在 `develop` 或独立功能分支进行。
- 未经项目所有者批准，不向 `main` 合并或直接写入。
- Codex 的职责是测试、构建和安装验证，不代替本项目的产品开发。
- 未通过目标 Harness 实机测试的功能，不标记为已验收。
